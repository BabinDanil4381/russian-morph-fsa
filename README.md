# Конечные автоматы и морфологический анализ — демо к докладу

## Установка

```
pip install pymorphy3 torch matplotlib
```
Для картинок автоматов нужен Graphviz (`dot`): https://graphviz.org/download/

## Запуск

```
python demo.py --step              # всё демо по шагам (Enter между шагами)
python demo.py мыла кружками       # разобрать свои слова мини-анализатором

cd neural
python analyzer.py зумеров загуглила            # гибридный анализатор
python analyzer.py --explain кружками           # показать работу автомата и сети
```

Обученная модель уже лежит в `neural/cache/` (model.pt, sa.pkl, metrics.json).
Переобучить с нуля (~2 часа на обычном процессоре):
```
cd neural
python data.py      # выгрузить данные из словаря OpenCorpora (~2 мин)
python train.py     # обучение нейросети
python compare_hybrids.py   # сравнение 5 способов объединить автомат и нейросеть
python charts.py    # графики для слайдов -> pictures/5_*.png, 6_*.png
```

## Файлы

| Файл | Что внутри | Часть доклада |
|---|---|---|
| `lexicon.py` | Мини-словарь: 5 парадигм, 8 лемм | Словарь: основа + номер парадигмы |
| `automata.py` | Trie, минимальный ДКА (Дачук), НКА с ε, построение подмножеств, минимизация Бжозовского | Теория ДКА/НКА |
| `morph.py` | Анализатор «словарь → DAWG» как в pymorphy2, НКА «основа · окончание» | Связь автомата и словаря |
| `viz.py` | Рисование автоматов через Graphviz | Картинки |
| `demo.py` | Демо из 8 шагов | Живое демо |
| `neural/data.py` | Выгрузка 750 тыс. словоформ из OpenCorpora, разбиение по леммам | Данные |
| `neural/suffix_automaton.py` | ДКА по перевёрнутым окончаниям со статистикой классов | Что ВОЗМОЖНО |
| `neural/model.py` | Нейросеть CharBiLSTM + функция потерь для омонимии | Что ВЕРОЯТНО |
| `neural/automata_bridge.py` | ДКА «возможных окончаний»: какие классы вообще применимы к слову | Фильтр |
| `neural/train.py` | Обучение нейросети (`--limit`, `--epochs`, `--out`) | Результаты |
| `neural/compare_hybrids.py` | Сравнение 5 вариантов: автомат / сеть / фильтры / байесовское объединение | Результаты |
| `neural/analyzer.py` | Гибридный анализатор для живого демо | Демо |
| `neural/charts.py` | Графики для слайдов | Слайды |
| `pictures/` | 1–4: автоматы, 5–6: результаты нейросети | Слайды |

## Результаты (20 000 незнакомых слов, доля правильных лемма + тег)

| Обучение | Автомат окончаний | Нейросеть | Автомат + нейросеть |
|---|---|---|---|
| 10 тыс. словоформ | 57.6% | 37.6% | 57.5% |
| 50 тыс. | 61.8% | 69.1% | 70.2% |
| 250 тыс. | 65.2% | 78.1% | 78.6% |

Мало данных — выручает автомат, много — нейросеть; сочетание всегда рядом с лучшим.
